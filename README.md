# Smart Laptop Recommendation System

## 📌 Project Overview

The **Smart Laptop Recommendation System** is a modern web application designed to help users choose the most suitable laptop based on their budget, performance requirements, and usage preferences.

The system uses a structured questionnaire and curated laptop data to provide intelligent, user-focused recommendations.
